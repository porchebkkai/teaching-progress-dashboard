# ระบบรายงานความคืบหน้าการสอน (Teaching Progress Dashboard)

Frontend redirect wrapper to bypass in-app browser restrictions (LINE, Facebook, Instagram) and smoothly launch the Google Apps Script Teaching Progress Dashboard for Iqra Muslim School.

## Links

- **Live GitHub Pages URL:** `https://porchebkkai.github.io/teaching-progress-dashboard/`
- **Backend Google Apps Script:** [Teaching Progress Dashboard Executable](https://script.google.com/macros/s/AKfycbwp1JblkFgo0vN57CF3XfCHuK0EABNaDZXNzof8rv1TvJf5JpscqoUhs7ZBVdGCA6Mm/exec)

## Features

- **In-App Browser Bypass:** Seamlessly escapes restricted in-app webviews (LINE, Facebook, IG, TikTok, WeChat) into native Chrome or Safari.
- **Brand Assets:** Includes Iqra Muslim School official logo, web favicons, and Apple touch icons.
- **Parameter Pass-through:** Transparently forwards URL query parameters and hashes to the Apps Script web app.
- **Direct Link Fallback:** Allows manual launch or in-app continuation if needed.
